# Distributed Systems

Este proyecto implementa una tienda distribuida de tres capas como una práctica
de sistemas distribuidos y alta disponibilidad. La solución utiliza servicios
replicados y mecanismos de balanceo, failover y persistencia para explorar cómo
se comporta una aplicación ante la falla de algunos de sus componentes.

## Origen del proyecto

Este repositorio es un **fork** de
[tuxtter/distributedsystems](https://github.com/tuxtter/distributedsystems).
El proyecto original contiene la descripción técnica detallada de la
arquitectura y de sus servicios.

## Enfoque de nuestro trabajo

Nuestro trabajo se centró principalmente en diseñar, ejecutar y documentar
pruebas sobre el sistema, incluyendo su comportamiento, rendimiento y
recuperación ante fallas. La documentación detallada, los escenarios y los
resultados pueden consultarse en la
[wiki de este proyecto](https://github.com/IanDiaz05/distributedsystems/wiki).

Para conocer los detalles técnicos de implementación, consulta también el
[README del repositorio original](https://github.com/tuxtter/distributedsystems).
